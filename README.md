# MOCABEAN CAFE 랜딩페이지

카페 소개를 위한 심플한 반응형 원페이지 랜딩페이지입니다.

## 미리보기

`index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## 구성

- `index.html` — 페이지 마크업
- `style.css` — 스타일
- `script.js` — 모바일 메뉴 토글, 맨 위로 가기 버튼 등 인터랙션

## 섹션

- **홈(Hero)** — 메인 카피와 메뉴/오시는 길 바로가기 버튼
- **소개(About)** — 카페 소개 및 특징
- **메뉴(Menu)** — 시그니처 메뉴 6종
- **갤러리(Gallery)** — 매장 이미지 영역
- **오시는 길(Location)** — 주소, 영업시간, 전화번호, 주차 안내

## 기술 스택

- HTML5 / CSS3 / Vanilla JavaScript (별도 프레임워크 없음)
